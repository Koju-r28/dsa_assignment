# Documentation of program(Undirected Graph using Adjacency Matrix (BFS & DFS))

## Introduction
 An undirected graph is represented using an adjacency matrix where each cell indicates the presence of an edge between two vertices.Graphs consist of vertices and edges. Traversal techniques like DFS and BFS explore all vertices systematically.

## Data Structure Used
    Adjacency Matrix

## Functions Specification

1.DFS(int v): Performs Depth First Search traversal starting from vertex v.
2.BFS(int v): (Conceptual) Traverses graph level by level using a queue.

## Algorithm
DFS explores deeply before backtracking. BFS explores level by level using a queue.
## Overview on main() function
The main() function initializes the graph and calls DFS traversal starting from vertex 0.
